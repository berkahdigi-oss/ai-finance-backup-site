Privacy Policy

AI Finance Backup

Effective date: November 6, 2026

1. Purpose

AI Finance Backup is a private utility designed to securely back up financial database snapshots to Google Drive.

2. Google Drive Access

The application requests the Google Drive drive.file permission. This allows access to files created or authorized for the application, including encrypted backups.

3. Data Usage

Google Drive access is used exclusively to create, store, verify, retrieve, and manage application backup files.

4. Data Storage and Security

Financial database backups are encrypted locally using Restic before being uploaded. OAuth credentials are stored in the private server environment.

5. Data Sharing

Google Drive data is not sold, used for advertising, or shared with unrelated third parties. Google Drive acts as the authorized backup storage provider.

6. Data Retention and Deletion

Backup files are retained according to the configured backup policy. The authorized user can delete stored backups and revoke application access through Google Account security settings.

7. Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including applicable Limited Use requirements.

8. Contact

For privacy questions, contact the project maintainer through the project repository.
